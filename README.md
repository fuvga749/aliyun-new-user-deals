## 优惠券规则：五条最容易踩的坑

阿里云优惠券分代金券、满减券、折扣券三种，单笔订单一次只能用一张。下单时系统会根据订单产品、支付类型和订单金额自动筛选可用券，显示在确认订单页；没显示出来，问题通常出在下面几件事上：

1. **优惠互斥**：部分优惠券与续费活动、新人首购优惠互斥。订单已经享受了其他折扣，券就不会出现。
2. **适用范围**：通用优惠券不适用于域名、商标、CDN、短信服务、语音服务等产品，云市场三方商品也不支持。自2023年6月8日起，标注“全部商品适用”的券不再支持抵扣语音服务、短信服务和轻量消息队列（MNS）的消费。买域名、CDN这类产品，别指望通用券能抵。
3. **数量上限**：每个账号最多同时持有50张有效优惠券，包括被未支付订单占用的冻结券。
4. **冻结与欠费**：下单选了券但没付款，券会停在“冻结”状态，作废未支付订单后恢复可用；优惠券无法抵扣欠费，欠费需要自己充值结清。
5. **按量付费自动抵扣**：按量付费的资源出账后，系统自动用券，优先使用快过期的券，单张余额不够会接着用下一张代金券。

企业用户如果持有多个阿里云账号，可以开通企业账号中心，把优惠券共享给组织内的其他账号，避免A账号领的券B账号用不上。

## 常见问题

### 为什么确认订单页看不到我领的优惠券？
先查三点：券是否适用于当前购买的产品和消费类型；满减券的门槛是否达到；是否已享受其他折扣（券与新人首购、续费活动等互斥）。手机端查看路径是“我的 > 费用成本 > 卡券”；电脑端看不到手机端领的券，先确认两端登录的是同一个阿里云主账号。

### 新用户优惠和优惠券能叠加吗？
看具体券。系统会在确认订单页自动筛选并展示可叠加的优惠券，能用的会显示，互斥的不会出现。记住单笔订单一次只能用一张券。

### 学生有专属优惠吗？
有。活动页设有高校学生专属权益，包括学生专属优惠券和算力包。其中大学生300元优惠券只能在学生用券中心使用，且仅适用于页面标注支持该券的指定商品——比如“大模型服务”页签里列出的百炼模型，并非百炼平台所有模型服务的账单都能抵扣。领之前先看清适用范围，别到结账时才发现用不了。

### 免费试用的服务器能备案吗？
不能。试用ECS不支持备案，这是试用条款里写明的。需要备案的网站直接选带安心备案服务的正式套餐，备案服务含快速审核和备案体检报告。
